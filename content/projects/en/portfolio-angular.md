## Personal Portfolio

This site is my personal portfolio, built with modern web technologies.

### Technologies used

- **Angular 19** with standalone components and Server-Side Rendering
- **SCSS** with CSS custom properties for dark/light theming
- **ngx-translate** for FR/EN internationalization
- **ngx-markdown** with PrismJS for blog post rendering
- **Docker** for containerized deployment

### Features

- Dark/light theme with persistence
- Bilingual French/English support
- Blog with Markdown rendering and syntax highlighting
- Responsive design
- Smooth animations and transitions
- Server-Side Rendering for SEO
