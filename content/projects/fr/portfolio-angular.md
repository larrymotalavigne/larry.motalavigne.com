## Portfolio Personnel

Ce site est mon portfolio personnel, construit avec les technologies modernes du web.

### Technologies utilisees

- **Angular 19** avec des composants standalone et le Server-Side Rendering
- **SCSS** avec des proprietes CSS personnalisees pour le theming dark/light
- **ngx-translate** pour l'internationalisation FR/EN
- **ngx-markdown** avec PrismJS pour le rendu des articles de blog
- **Docker** pour le deploiement containerise

### Fonctionnalites

- Theme sombre/clair avec persistance
- Support bilingue francais/anglais
- Blog avec rendu Markdown et coloration syntaxique
- Design responsive
- Animations et transitions fluides
- Server-Side Rendering pour le SEO
